# &#x20;AVAA Antivirus Application

# 

# Windows приложение с системным треем, Windows службой, RPC (ALPC), аутентификацией и лицензированием.

# 

# &#x20;Возможности

# 

# \- Иконка в системном трее (левая кнопка - открыть окно, правая - контекстное меню)

# \- Windows служба для запуска приложения во всех пользовательских сессиях

# \- RPC взаимодействие через ALPC (ncalrpc)

# \- Аутентификация пользователей

# \- Лицензирование и активация продукта

# \- Антивирусное сканирование файлов и директорий

# \- Планировщик сканирования

# \- Мониторинг директорий

# \- Обновление антивирусных баз

# 

# &#x20;Требования

# 

# \- Windows 10/11

# \- Visual Studio 2022 Build Tools или Visual Studio 2022

# \- Windows SDK

# \- CMake 3.20+

# 

# &#x20;Сборка

# 

# ```bash

# mkdir build

# cd build

# cmake .. -G "Visual Studio 17 2022" -A x64

# cmake --build . --config Release
