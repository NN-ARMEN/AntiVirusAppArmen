# AVAA - Windows Tray Application

## Описание
AVAA (AntiVirusAppArmen) - это приложение для Windows, которое работает в системном трее и демонстрирует все основные возможности работы с иконкой в области уведомлений.

## Функциональность

### Основные возможности
- Иконка в системном трее (область уведомлений)
- Левая кнопка мыши - показывает/скрывает главное окно
- Правая кнопка мыши - показывает контекстное меню
- Контекстное меню содержит пункты "Открыть" и "Выход"
- Автоматическое восстановление иконки при пересоздании панели задач
- Запуск без показа главного окна (только иконка в трее)
- Закрытие главного окна скрывает его в трей (приложение продолжает работать)
- Меню "Файл" -> "Выход" в главном окне
- Только один экземпляр приложения может быть запущен (используется именованный мьютекс)

## Требования для сборки

- Windows 10/11
- Visual Studio 2022 (с компонентами C++)
- CMake 3.15 или выше

## Сборка проекта

### Через командную строку

```bash
mkdir build
cd build
cmake .. -G "Visual Studio 17 2022" -A Win32
cmake --build . --config Release
"" 
""
